# A song recorded in another language is a separate, linked song

A song is sung in one song language or a mix; when the author records the same song in another language, that recording is a separate Song (own folder, original lyrics, SoundCloud track, URL) linked to the other through `language-versions`, not a second lyrics file of one song. Every other lyrics file of a song is an automatic lyrics translation: lyrics only, no chords, marked as such on the site. This keeps "what is sung" (original lyrics + chords, one recording) apart from "what helps to understand it" (translations), so filters by song language, chord pages, PDFs and the songbook only ever show performed lyrics.

## Considered Options

- One song with several sung lyrics files: simpler folders, but two recordings would share one SoundCloud link and one date, and chords would have to be kept in sync across files.
